Haptic Joystick

Programming and Designing and Haptic Joystick using Advanced Mechatronics

Overview

As part of MECH-ENG 433, Advanced Mechatronics, the final project was making a joystick with custom haptic effects in order to utilize the material we covered in class.

As part of the project, I had to rapid prototype a robust joystick, integrate motor control, and utilize an STM32 and Raspberry Pi Pico 2 to create a fully functional haptic joystick from scratch.

Design Process

Electronics Workflow

Step 1: Defining Setup and Required Tools

I first had to decide on the components to be included in this project and how they would be setup to allow for haptic control. Due to time and resources, we were given deconstructed servo motors, load-cells, potentiometers, an STM-32, a current sensor, H-bridge, and Raspberry Pi Pico

The basic workflow was this: the STM-32 would run motor control for the servo using the H-bridge and current sensor, then via CAN, the STM-32 would receive what current was desired from the Pico based on computer graphics given by the computer and force sensor.

Additionally, we made force diagrams to simulate the haptic effect.

Step 2: Implementation

In actual implementation, the system operated on the following closed-loop workflow:

  1. The computer rendered the virtual environment and transmitted the desired haptic state, including the target current corresponding to the simulated force — to the Raspberry Pi Pico.
  2. The Raspberry Pi Pico processed the incoming haptic command and determined the appropriate current setpoint based on the virtual wall position and the force-displacement model.
  3. The Pico transmitted the current setpoint to the STM32 via CAN bus, providing a robust and noise-resistant communication channel between the two controllers.
  4. The STM32 executed low-level motor control, driving the servo motor through the H-bridge and continuously monitoring actual motor current via the current sensor to close the PI current control loop in real time.
  5. The potentiometer provided continuous position feedback, allowing the system to track handle position and determine when the virtual wall boundary had been crossed.
  6. The load cells measured the actual force applied by the user, feeding back into a PID-control loop against desired force to create the desired haptic effect.

Additionally, I utilized Onshape and Rapid Prototyping to design a holder for the servo-motor and joystick attachment that would account for these electronics

Step 3: Testing & Troubleshooting

Testing revealed several practical challenges that required iterative debugging across both the hardware and software layers of the system.

Signal Integrity & Noise
The current sensing and load cell signal chains were particularly susceptible to electrical noise, which introduced instability into the haptic response and made the force feedback feel erratic rather than smooth. Addressing this required careful attention to circuit layout, grounding strategies, and signal filtering, including tuning low-pass filters on the sensor outputs to attenuate high-frequency noise while preserving the signal bandwidth needed for responsive force control. This process involved significant trial and error, as overly aggressive filtering introduced lag that degraded the haptic feel, while insufficient filtering left too much noise in the control loop.

PID Tuning & Haptic Feel
The most iterative part of testing was tuning the PID controllers governing motor current and position to produce a haptic effect that felt realistic and stable to the user. The wall effect in particular was sensitive to controller gains, aggressive proportional gains produced a snappy, unstable response that caused the motor to oscillate at the wall boundary, while gains that were too low made the wall feel soft and unconvincing. Achieving a smooth, rigid wall effect required careful balancing of the proportional, integral, and derivative terms across different operating conditions, including varying approach speeds and force magnitudes. Each tuning iteration was validated by feel, with the target being a wall that engaged crisply, held firm under sustained force, and released cleanly when the user withdrew.
