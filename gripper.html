Open-Source Surgical Gripper

Macro-sized Surgical Gripper inspired by Intuitive Surgical

Overview

Intuitive Surigcal was one of the companies that first inspired me to become an engineer. Looking at a break down of one of their grippers, I wanted to design a low-cost fully 3D printed Gripper inspired by their design.

For the summer of 2026, I've fully 3D designed, printed, and programmed an interface to control the gripper . I'm going to work on making a custom hapatic interface next to control with your fingers, with potential applications as low-cost prosthetic.

Research/Design Process

CAD of Gripper

Step 1: Initial Design V1

I began sketching out designs inspired by videos I had seen of Intuitive Surgical instruments. The goal was to make a similar design but implementing low cost alternatives to otherwise expensive parts while still being functional. To do this, I designed things with manufacturing in mind, making designs that worked well 3D printed and made use of inexpensive parts like heat-inserts and low cost rope.

This design includes implementing pulley routing for cables, attachments to link subsystems together, and ensuring wrist movement. This led to an initial design called V1 which featured very basic geometry that would allow the system to just work with basic testing.

Step 2: Testing and Programming

Once the initial design was built, I tested it by placing tendons in quickly and seeing how the grippers moved. I analyzed the friction generated, the physical deflection of different parts, and the tension in the ropes. From the basic values I got, I could make data driven design choices that allow me to redesign the grippers for V2.

Some of the conclusions I came to was the need for less deflection, so I implemented more filets and mass on to the gripper to prevent deflection. Additionally, I adjusted the tolerances to reduce friction on the bushings. This was printed into V2 which, using FEA verification, I decided to test with all tendons attached

Finally, I also began programming the system using a Raspberry Pi Pico 2 for embedded control of the servos. This included programming in C to control the servos using PWM and then making a python interface to control the gripper using my computer.

Step 3: Final Testing and Next Steps

Once I installed everything onto the system. I began testing the program and the entire system to see how the system behaved. This included taking detailed notes and documentation to see what improvements were needed.

The system overall worked well, moving each gripper and wrist independently of one another aside from edge cases, similar to how the Intuitive Surigcal system behaved. However a couple improvements can be made. Rope tensioning I found was a massive issue where it was difficult to tension ropes to where the system was fully effective. Additionally, friction was a big issue as well between the 3D printed bushings. Finally, the Raspberry Pi had natural limitations that could be fixed by using a more powerful microcontroller. All of these issues will hopefully be solved in V3 which is still a work in progress along with a potential user interface using haptic control.
